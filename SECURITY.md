# Security

## Supported versions

The latest version on `main`.

## Reporting a vulnerability

Private vulnerability reporting is not enabled for this repository. Open a [GitHub issue](https://github.com/bennewton999/claude-code-mods/issues/new) without exploit details and mention the maintainer @bennewton999.

## What this repository is

The marketplace manifest describes five Claude Code mods: a fleet board, a PR-to-production tracker, rule tripwires, a side-effects ledger, and a context gauge. The session-activity plugin manifest names the `/ledger` command.
